# LeArm 机械臂标定文档

## 1. 坐标系

```
原点 = 工作区左下角
X轴 下→上  0 ~ 20.9 cm
Y轴 左→右  -14.7 ~ +14.7 cm (总 29.4cm)

视觉坐标系 Y 范围 ±14.85cm → 机械臂 Y 范围 ±14.7cm
映射: y_arm = y_vis × 14.7 / 14.85
```

## 2. 定位算法

### XY 平面: 线性拟合

17 个标定点 → 最小二乘平面拟合：

```
dx = 9.6 × X + 0.3 × Y - 26
dy = -0.3 × X + 10.0 × Y - 6
```

| 系数 | 说明 |
|------|------|
| dx | CMD_COORDINATE_SET 的 X 增量 (mm) |
| dy | CMD_COORDINATE_SET 的 Y 增量 (mm) |
| X, Y | 目标纸面坐标 (cm) |

拟合残差: dx_max=17, dy_max=11

### Z 轴 (抓取高度): IDW 插值

17 个实测 grip dz 值 → 逆距离加权 (power=2)：

```
给定 (x, y):
  找库中所有 grip 层锚点
  权重 w = 1 / distance²
  dz = Σ(w × dz_i) / Σw
  若命中锚点 (d < 0.3cm) → 直接用锚点值
```

安全高度 = grip_dz + 35mm

### 到目标位置的完整流程

```
home() → CMD_COORDINATE_SET(dx, dy, safe_dz) → 机械臂到安全高度
       → CMD_COORDINATE_SET(0, 0, grip_dz - safe_dz) → 下降到抓取面
       → 等待吸合
       → CMD_COORDINATE_SET(0, 0, safe_dz - grip_dz) → 上升到安全高度
```

## 7. 修改参数指南

### 全点 XY 偏移
修改 `pick_and_place.py` idw_xyz() 中的常数:
- dx 常数: 改大 = X正向移
- dy 常数: 改大 = Y正向移

### 单个点 Z 修正
编辑 `ikine_lib.json` → 找到该点 grip 层 → 修改 dz 值
(更负 = 更低)。同时更新 safe 层 dz = grip_dz + 35。

### 添加新锚点
在 `ikine_lib.json` 添加两组:
```json
{"x":X,"y":Y,"dx":DX,"dy":DY,"dz":DZ,"layer":"grip"},
{"x":X,"y":Y,"dx":DX,"dy":DY,"dz":DZ+35,"layer":"safe"}
```
DX/DY 从线性拟合公式计算。
