## 一、系统架构

```
摄像头 (4K USB, /dev/video0, MJPG 1280×720)
    │
    ▼
┌─────────────────────────────────────────────┐
│  1. 摄像头自动控制                           │
│     AE (auto_exposure=3) + AWB (auto)       │
│     光照变化自动适应，无需手动调参             │
└──────────────────┬──────────────────────────┘
                   │ BGR 帧
┌──────────────────┴──────────────────────────┐
│  2. A4 纸定位 + 透视矫正                     │
│     深色纸 + 白色角标                        │
│     Canny + V 通道亮斑 → 四点提取            │
│     → getPerspectiveTransform → 标准俯视图    │
│     找不到纸退回原图，状态栏显示 Raw           │
└──────────────────┬──────────────────────────┘
                   │ 俯视图 (210×297mm @ 3px/mm)
┌──────────────────┴──────────────────────────┐
│  3. Gamma 亮度自适应（安全区 80-160）         │
│     计算上半区平均亮度                        │
│     < 80 → Gamma < 1 提亮                    │
│     > 160 → Gamma > 1 压暗                   │
│     80-160 → 不触发，原图直通                 │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────┴──────────────────────────┐
│  4. CLAHE 局部增强                           │
│     V 通道 CLAHE (clipLimit=2.0, grid=8×8)  │
│     暗处提亮、亮处压暗、阴影减弱              │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────┴──────────────────────────┐
│  5. V 通道 OTSU 自动阈值 + Canny 边缘融合     │
│     OTSU 自动计算最优分界 → ×0.85 保留边缘    │
│     深底板 V低 / 白碎片 V高 → 双峰直方图      │
│     Canny 在 OTSU 核心区膨胀范围内融合         │
│     分界线中间窄带排除（mask[mid±8] = 0）     │
└──────────────────┬──────────────────────────┘
                   │ 二值 Mask
┌──────────────────┴──────────────────────────┐
│  6. 形态学 + 轮廓恢复                        │
│     Close(5×5)→Open(5×5)→Dilate(3×3)       │
│     → convexHull → approxPolyDP             │
│     → minAreaRect 外接矩形                   │
└──────────────────┬──────────────────────────┘
                   │ 碎片多边形 + 定位框
┌──────────────────┴──────────────────────────┐
│  7. 拼图验证                                 │
│     碎片在矩形坐标系中已处于正确位置            │
│     → 相邻碎片检测（共享顶点 < 2mm）           │
│     → 2cm 约束验证（赛题评分标准）             │
└─────────────────────────────────────────────┘
```

## 二、检测策略

### 核心原理

**深色底板 + 白色碎片** → V 通道（亮度）天然形成双峰直方图。OTSU 自动找到最优分界阈值，不受光照变化影响。

```
  V 直方图
  
  底板峰 ████████
  (V 20-60)
              ████████ 碎片峰
              (V 150-240)
         ↑
      OTSU 取这里
```

### 为什么 V 通道比 HSV 更鲁棒

| | H 通道（色相） | V 通道（亮度） |
|---|---|---|
| 反光影响 | 色相偏移 → 漏检 | 对比度增强 → 更稳 |
| 色温变化 | 需重新调 H 范围 | 无影响 |
| 多场景覆盖 | 只覆盖一种颜色 | 深底+浅片全场景 |

### 三场景检测

| 场景 | 底板 | 碎片 | 策略 |
|---|---|---|---|
| 要求 1（自备） | 深色（自定） | 任意亮色 | V 通道 OTSU |
| 要求 2a（现场） | 深色（自定） | 白色（现场给） | V 通道 OTSU |
| 要求 2b（现场） | 深色（自定） | 扑克牌（现场给） | V 通道 OTSU + Canny 纹理 |

## 四、实时检测参数

### 4.1 V 通道 OTSU

| 参数 | 值 | 说明 |
|---|---|---|
| OTSU_FACTOR | 0.85 | OTSU 阈值系数，<1 多保留边缘 |
| 底板 V 值 | ~20-60 | 深色背景，光照越暗越低 |
| 碎片 V 值 | ~150-240 | 白色碎片，光照越亮越高 |

### 4.2 CLAHE

| 参数 | 值 |
|---|---|
| clipLimit | 2.0 |
| tileGridSize | 8×8 |

### 4.3 Gamma 校正

| 参数 | 值 |
|---|---|
| 目标亮度 | 120 |
| 安全区 | 80 ~ 160（不触发） |
| Gamma 限制 | 0.5 ~ 2.0 |

### 4.4 形态学

| 步骤 | 参数 | 作用 |
|---|---|---|
| Close | ELLIPSE 5×5, 2次 | 填内部孔洞 |
| Open | ELLIPSE 5×5, 1次 | 去外部噪点 |
| Dilate | ELLIPSE 3×3, 1次 | 补偿边缘损失 |

### 4.5 轮廓恢复

| 步骤 | 作用 |
|---|---|
| convexHull | 填凹陷，补缺角 |
| approxPolyDP | 多边形逼近，epsilon=0.008×周长 |
| minAreaRect | 旋转外接矩形定位 |

## 五、数据集生成规格

### 5.1 赛题 Fig2 精确模式

- 目标矩形：100mm × 60mm（固定）
- 碎片：4 个，边数 3-4，符合赛题图 2

### 5.2 随机自定义裁切模式

| 参数 | 范围 | 约束 |
|---|---|---|
| 矩形宽度 | 90 ~ 120mm | 赛题 9~12cm |
| 矩形高度 | 50 ~ 90mm | 赛题 5~9cm |
| 碎片数 | 4 | 固定 |
| 每碎片边数 | 3 ~ 5 | 赛题 ≤5 |
| 每边长度 | ≥ 20mm | 赛题 ≥2cm |
| 外边 | ≥ 1 条/碎片 | 赛题要求 |
| 碎片间距 | ≥ 3mm | 防止轮廓粘连 |

### 5.3 配色

| 对象 | 颜色 | 说明 |
|---|---|---|
| 底板 | 深色（自定） | V 值低，与碎片形成双峰 |
| 碎片（要求1） | 白色或亮色 | V 值高，与底板形成对比 |
| 碎片（要求2a） | 白色（现场给） | V 值高 |
| 碎片（要求2b） | 扑克牌图案（现场给） | 白底彩色图案 |
| 分界线 | 与底板同色或浅色 | 3mm 宽，OTSU 后中间窄带排除 |

## 八、状态栏说明

```
Frags:4 | Warp | OTSU(128) | Bri:118 | 15.2fps
```

| 字段 | 含义 | 可能值 |
|---|---|---|
| Frags | 检出碎片数 | 0 ~ N |
| Warp/Raw | 透视矫正状态 | Warp=已矫正 / Raw=未找到纸 |

| Bri | ROI 上半区平均亮度 | 0 ~ 255 |
| G | Gamma 校正值 | 偏离 1.0 时显示 |
| fps | 实时帧率 | — |

## 九、鲁棒性设计

| 光照场景 | Gamma | CLAHE | OTSU | 结果 |
|---|---|---|---|---|
| 正常光 (80-160) | 不触发 | 轻微增强 | 正常双峰 | ✅ |
| 暗光 (<80) | Gamma<1 提亮 | 拉伸灰度 | 降阈值 | ✅ |
| 强光 (>160) | Gamma>1 压暗 | 均衡 | 升阈值 | ✅ |
| 极端暗光 | Gamma 提亮 | 拉伸 | 双峰可能粘连 | ⚠️ 物理极限 |
